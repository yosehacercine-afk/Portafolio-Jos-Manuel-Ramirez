# Archivo Visual Jose Manuel Ramirez

Portafolio estatico disenado como archivo visual curado: perfil, frames, reel, hoja de vida PDF y nota autoral breve.

- Web publicada: https://yosehacercine-afk.github.io/Portafolio-Jos-Manuel-Ramirez/
- HV PDF: https://yosehacercine-afk.github.io/Portafolio-Jos-Manuel-Ramirez/hv-jose-manuel-ramirez.pdf
- Repositorio: https://github.com/yosehacercine-afk/Portafolio-Jos-Manuel-Ramirez
- Publicacion: GitHub Pages desde rama `main`, carpeta `/`.

## Estructura

- `index.html`: estructura editorial del archivo visual.
- `hv-jose-manuel-ramirez.html`: fuente HTML de la hoja de vida PDF.
- `hv-jose-manuel-ramirez.pdf`: hoja de vida final descargable.
- `css/styles.css`: direccion visual, grilla responsive y estados sutiles.
- `js/main.js`: comportamiento minimo.
- `assets/images`: imagenes locales del sitio y retrato del PDF.
- `assets/video/portafolio-reel.mp4`: reel integrado.

## Criterio tecnico

El proyecto no usa framework para mantener carga rapida, baja complejidad y control total sobre la experiencia visual. La direccion actual evita lenguaje comercial y prioriza una experiencia de archivo cinematografico.

## Seguridad

No subir tokens, archivos `.env`, scripts locales, enlaces temporales con token ni carpetas antiguas del bridge. El sitio esta marcado `noindex` y `robots.txt` bloquea indexacion accidental.
